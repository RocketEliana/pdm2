Misma forma de pin, solo cambia el color usando las constantes HUE_*.

    MarkerOptions()
        .position(madrid)
        .title("Madrid")
        .icon(

                .defaultMarker(
                    BitmapDescriptorFactory
                        .HUE_BLUE
                )
        )
)

Icono desde Bitmap (escalar imagen)
bitmap

Útil para redimensionar el icono antes de aplicarlo al marcador.

fun bitmapFromDrawable(context: Context, resId: Int, width: Int, height: Int): BitmapDescriptor {
    val drawable = ContextCompat.getDrawable(context, resId)!!
    val bmp = Bitmap.createBitmap(width, height, Bitmap.Config.ARGB_8888)
    val canvas = Canvas(bmp)
    drawable.setBounds(0, 0, width, height)
    drawable.draw(canvas)
    return BitmapDescriptorFactory.fromBitmap(bmp)
}

// Uso:
val icono = bitmapFromDrawable(requireContext(), R.drawable.mi_icono, 80, 80)
mMap.addMarker(MarkerOptions().position(madrid).icon(icono))
Snippet — subtítulo en la burbuja
snippet

Al tocar el marcador aparece una burbuja nativa con título y subtítulo. Sin código adicional, funciona directo.

mMap.addMarker(
    MarkerOptions()
        .position(madrid)
        .title("Madrid")
        .snippet("Capital de España\nPoblación: 3.3M")
)
Madrid Capital de España · Población: 3.3M
→ Así se ve al tocar el marcador
El snippet acepta saltos de línea con \n pero no soporta HTML ni estilos. Para eso, usa InfoWindowAdapter (siguiente tab).

InfoWindowAdapter en Kotlin
adapter

Implementa el adaptador en tu onMapReady:

mMap.setInfoWindowAdapter(object : GoogleMap.InfoWindowAdapter {

    override fun getInfoWindow(marker: Marker): View? {
        return null // null = fondo estándar + nuestro contenido
    }

    override fun getInfoContents(marker: Marker): View {
        val view = layoutInflater.inflate(
            R.layout.custom_info_window, null
        )
        val datos = marker.tag as? Map<*, *>

        view.findViewById<TextView>(R.id.infoTitulo)
            .text = marker.title
        view.findViewById<TextView>(R.id.infoDescripcion)
            .text = datos?.get("descripcion") as? String
                    ?: marker.snippet

        val imgRes = datos?.get("imagen") as? Int
        if (imgRes != null) {
            view.findViewById<ImageView>(R.id.infoImagen)
                .setImageResource(imgRes)
        }
        return view
    }
})
Importante: Las InfoWindow son snapshots estáticos, no vistas vivas. Si cargas imágenes con Glide o Picasso, debes llamar marker.showInfoWindow() cuando la imagen termine de cargar para refrescar el snapshot.
Adjuntar datos al marcador
tag

El campo tag permite guardar cualquier objeto en el marcador sin variables globales.

val marker = mMap.addMarker(
    MarkerOptions()
        .position(madrid)
        .title("Madrid")
)

marker?.tag = mapOf(
    "imagen"      to R.drawable.madrid_foto,
    "descripcion" to "Ciudad fundada en el siglo IX",
    "poblacion"   to 3_300_000,
    "url"         to "https://madrid.es"
)

Data class (mejor práctica)
data class

En vez de un Map, usa una data class tipada:

data class LugarInfo(
    val descripcion: String,
    val imagen: Int,
    val url: String
)

marker?.tag = LugarInfo(
    descripcion = "Fundada siglo IX",
    imagen = R.drawable.foto,
    url = "https://madrid.es"
)

// Lectura limpia y con tipos:
val info = marker.tag as? LugarInfo
Tabla de referencia rápida
Método Para qué sirve Complejidad
.icon() Cambiar la imagen/color del pin baja
.title() Título en la burbuja al tocar baja
.snippet() Subtítulo simple bajo el título baja
marker.tag Guardar datos extra en el marcador media
setInfoWindowAdapter Burbuja completamente personalizada con imagen alta
setOnInfoWindowClickListener Acción al tocar la burbuja emergente media
setOnMarkerClickListener Acción al tocar el pin directamente media
marker.showInfoWindow() Forzar refresco del InfoWindow (p.ej. tras cargar imagen) media
Recuerda: Los InfoWindow son snapshots — una vez renderizados no se actualizan solos. Si cargas imágenes asíncronas (Glide, Picasso, Coil), llama marker.showInfoWindow() en el callback de la imagen para forzar el redibujado.
