📘 Colecciones y Funciones en Kotlin

Guía completa de colecciones y funciones de orden superior

1️⃣ Colecciones en Kotlin

Tipo Descripción Ejemplo
List Colección ordenada e inmutable (no cambia después de creada) val lista = listOf(1, 2, 3)
MutableList Colección ordenada y mutable (puedes agregar, eliminar, modificar) val lista = mutableListOf(1, 2, 3)

2️⃣ Funciones de Orden Superior

Estas funciones operan sobre colecciones para transformarlas, filtrarlas, o realizar acciones específicas sin modificar directamente los objetos originales (excepto en algunos casos).

3️⃣ Funciones Principales

Función Propósito Ejemplo básico Nota
map Transforma cada elemento de la colección en otro elemento lista.map { it.nombre }
devuelve lista de nombres		 Crea una nueva colección
filter Filtra elementos que cumplen una condición lista.filter { it.enStock }
devuelve productos en stock		 Crea una nueva colección con elementos filtrados
forEach Ejecuta una acción en cada elemento, sin devolver colección lista.forEach { println(it) } Usado para efectos o impresiones
reduce Combina todos los elementos en un solo valor usando una función numeros.reduce { acc, x -> acc + x } Para sumar, multiplicar, etc.
any / all Verifica si algún o todos los elementos cumplen una condición lista.any { it.enStock }
lista.all { it.enStock }		 Devuelven true o false
find / first Encuentra primer elemento que cumple condición lista.find { it.nombre == "mesa" } Devuelve elemento o null

4️⃣ Funciones de Contexto

Función Propósito Uso típico Ejemplo
let Ejecuta un bloque si la variable no es null, devuelve resultado Para trabajar con valores no nulos o transformar valor?.let { println(it) }
apply Ejecuta un bloque en el objeto, devuelve el objeto Para configurar objetos persona.apply { nombre = "Juan" }
run Ejecuta un bloque y devuelve el resultado del bloque Similar a let, pero más general resultado = lista.run { size }
with Ejecuta un bloque en un objeto, devuelve el resultado Para realizar múltiples operaciones en un objeto with(persona) { nombre = "Juan"; edad = 30 }

5️⃣ Propiedades y Métodos Útiles

Propiedad / Método Propósito Nota
copy() Crea una copia del data class, con posibilidad de modificar algunos atributos Solo en data classes
toString() Devuelve una representación en cadena del objeto Útil para imprimir objetos
var / val var: variable mutable
val: inmutable		 Modificar var en objetos

6️⃣ Ejemplo Completo

Supón que tienes una lista de productos y quieres:

  1. Filtrar los en stock
  2. Modificar algunos atributos
  3. Crear una lista nueva con cambios
data class Producto(val nombre: String, val precio: Double, var enStock: Boolean) fun main() { val lista = listOf( Producto("boli", 2.5, true), Producto("mesa", 22.5, true), Producto("tiza", 2.5, false) ) // Filtrar productos en stock val enStock = lista.filter { it.enStock } // Modificar todos los productos para que estén en stock lista.forEach { it.enStock = true } // Crear una lista nueva con map y copy val listaModificada = lista.map { it.copy(enStock = false) } // Imprimir resultados enStock.forEach { println(it) } listaModificada.forEach { println(it) } }

📝 Resumen Visual

🔹 map - Transformar

Propósito: Transforma cada elemento en otro

val nombres = productos.map { it.nombre } // [Producto1, Producto2, Producto3] → ["boli", "mesa", "tiza"]

🔹 filter - Filtrar

Propósito: Filtra elementos que cumplen condición

val enStock = productos.filter { it.enStock } // Solo devuelve productos con enStock = true

🔹 forEach - Recorrer

Propósito: Ejecuta acción en cada elemento

productos.forEach { println(it.nombre) } // Imprime: boli, mesa, tiza

🔹 reduce - Combinar

Propósito: Combina todos los elementos en uno solo

val suma = listOf(1, 2, 3, 4).reduce { acc, x -> acc + x } // suma = 10

🔹 any / all - Verificar

Propósito: Comprueba si alguno o todos cumplen condición

val hayEnStock = productos.any { it.enStock } // true si al menos uno val todosEnStock = productos.all { it.enStock } // true si todos

🔹 find / first - Buscar

Propósito: Encuentra el primer elemento que cumple condición

val mesa = productos.find { it.nombre == "mesa" } // Devuelve Producto("mesa", 22.5, true) o null

📋 Funciones de Contexto - Ejemplos

🔹 let

Uso: Trabajar con valores no nulos

val nombre: String? = "Juan" nombre?.let { println("Hola, $it") } // Solo si no es null

🔹 apply

Uso: Configurar objetos

val persona = Persona().apply { nombre = "Juan" edad = 30 } // Devuelve el objeto persona configurado

🔹 run

Uso: Ejecutar bloque y devolver resultado

val tamano = productos.run { size } // tamano = 3

🔹 with

Uso: Operar sobre un objeto

with(persona) { nombre = "Juan" edad = 30 println("$nombre tiene $edad años") }

🎯 Resumen Final

  • ✅ Usa map para transformar listas
  • ✅ Usa filter para filtrar elementos
  • ✅ Usa forEach para recorrer y realizar acciones
  • ✅ Usa copy() en data classes para crear versiones modificadas
  • ✅ Usa let, apply, run, with para manipular objetos en contextos específicos
